One true sentence about the dumbest thing my agent did today: while
fetching this competition's requirements, it pasted the literal word
"redacted" as the API key, got a 401, and spent five minutes convinced
the key had been revoked. `main.py` writes that single sentence to
`$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
